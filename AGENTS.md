# AGENTS.md

Pilates Booker is a reliable personal automation tool for a private, single-user runtime. Apply pragmatic, proportional engineering judgment: protect against realistic mistakes, ordinary failures, unintended submissions, charges, and disclosure of private information without designing it as a hostile-environment, production, or high-assurance system.

Before working, read the complete source issue and the relevant sections of `README.md`, `docs/architecture.md`, and `docs/safety-boundaries.md`. Follow `CONTRIBUTING.md` and `SECURITY.md` for anything that may become public. Keep changes within the approved issue scope and use synthetic evidence in all public GitHub content.

Open completed pull requests in Ready for Review status. Do not merge them.

Monitor each pull request and address up to three review rounds. Verify every comment's premise and classify it as:

- systemic;
- localized;
- repetitive symptom treatment;
- a request beyond the project's stated reliability posture.

Prefer one systemic correction over successive special cases. Push and test a fix before replying that it is resolved, and resolve a review thread only after the fix is pushed. Pause and ask the user for instructions if a fourth review round occurs or Codex gives the pull request a thumbs-up emoji.
