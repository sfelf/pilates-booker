# Contributing

Contributions are considered case by case. This project provides no response, support, or acceptance guarantee.

Respectful, privacy-conscious participation is required. Public issues and pull requests must not include booking URLs, checkout URLs, class details, package names or details, logs containing private values, request or policy contents, cookies, tokens, authenticated captures, browser profiles, injury information, real customer data, or unsafe diagnostics. Use synthetic descriptions that demonstrate the behavior without private evidence.

For security vulnerabilities, use the private reporting route in [SECURITY.md](SECURITY.md). Do not create a public issue or pull request for a vulnerability report.
